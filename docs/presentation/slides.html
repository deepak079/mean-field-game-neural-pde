The problem

Grow your wealth, but don’t end below the average

  1. Each investor keeps π dollars in a stock and the rest in the bank
  2. Luck spreads their wealth apart
  3. At the end, everyone is compared with the average mT
  4. Ending below it costs a penalty that grows with the gap squared
  5. Everyone’s choices set the average, and the average shapes everyone’s choice

The problem · the equilibrium

Two equations, tied together by one number

HJB

each investor’s best strategy

◀ solved backward, T → 0

\[ \begin{gathered} \partial_t V + \sup_{\pi}\Big\{\big[r x + \pi\,(\mu - r)\big]\,\partial_x V + \tfrac12\,\sigma^2\pi^2\,\partial_{xx} V\Big\} = 0 \\[2pt] V(T,x) = U(x, \cC{\bar m_T}) \end{gathered} \]
\[ \pi^*(t,x) = -\frac{\mu - r}{\sigma^2}\,\frac{\partial_x V}{\partial_{xx} V} \]

the best strategy moves the crowd

Fokker–Planck

how wealth spreads in the crowd

solved forward, 0 → T ▶

\[ \begin{gathered} \partial_t m + \partial_x\big[(r x + (\mu - r)\,\pi^*)\,m\big] - \tfrac12\,\partial_{xx}\big[\sigma^2(\pi^*)^2\,m\big] = 0 \\[2pt] m(0,x) = m_0(x) = \mathcal{N}(1,\ 0.2^2) \end{gathered} \]
\[ \cC{\bar m_T} = \int x\, m(T,x)\,dx \]

the crowd’s average

Equilibrium: the average the HJB assumes is the average the Fokker–Planck equation delivers.

The best strategy against that average

Step 3 · the m network

Where the wealth goes

\[ \begin{gathered} \partial_t m + \partial_x\big[(r x + (\mu - r)\,\pi^*)\,m\big] - \tfrac12\,\partial_{xx}\big[\sigma^2(\pi^*)^2\,m\big] = 0 \\[2pt] m(0,x) = \mathcal{N}(1,\ 0.2^2) \end{gathered} \]

A second PINN solves Fokker–Planck forward from t = 0, with everyone playing \(\pi^*\)
